# 接口与数据结构说明

## 一、命令行入口（`schem_gen.py`）

所有命令默认纯本地离线执行，无网络访问、无 SSH 连接、无电路仿真调用；输出目录自动创建。

| 子命令 | 用途 | 核心输入 | 核心输出 |
| :--- | :--- | :--- | :--- |
| `analyze` | 解析网表、提取模拟电路基元候选并生成草案 `Intent` | `.spice` / `.cdl` / `.scs` 网表 | `analysis.json`, `intent.draft.json` |
| `compile` | 按确认后的 `intent.json` 执行约束布局、正交分轨布线、SVG 渲染与双重签核 | 网表 + `intent.json` + `process-map` | `manifest.json`, `canvas_ir.json`, `preview.svg`, `audit.json`, `audit.md` |
| `auto` | 零样本全自动模式（直接采用 `analyze` 生成的草案 `Intent` 编译） | 网表 | 同 `compile` + `analysis.json` |
| `refine` | 保结构整理既有草图（保留原图行列顺序与朝向，撑开过挤区、收紧过大空白并重布线） | 既有 `manifest.json` | 整理后 `manifest.json`, `preview.svg`, `refine_comparison.json` |
| `audit` | 独立对任意 `virtuoso-bridge-exact-schematic-v1` 清单做 LVS + 可读性 DRC | `manifest.json` [+ 基准网表] | `audit.json`, `audit.md` |
| `probe-pdk` | 校验已授权 Virtuoso 会话中的真实符号引脚偏移（未加 `--live` 时仅打印离线说明） | `--pdk-map` [--live] | 终端核对结果 / JSON |
| `demo` | 一键运行内置 3 组 SKY130 代表性基准案例 | `--out <dir>` | 3 组完整产物 + `demo_summary.json` |

## 二、`SchematicIntent`（`schem_gen.intent.v1`）字段契约

`intent.json` 是大模型与底层几何求解器之间的唯一控制面，**不含任何像素或浮点坐标**：

```json
{
  "schema": "schem_gen.intent.v1",
  "cellName": "sky130_two_stage_ota",
  "authoredBy": "llm_agent",
  "llmNotes": "简记本轮排图决策依据",
  "groups": [
    {
      "id": "input_diff",
      "label": "第一级差分输入",
      "role": "input_diff",
      "stage_order": 10,
      "instances": ["M3", "M4", "M1", "M2", "M5"]
    }
  ],
  "motifs": [
    {
      "type": "diff_pair",
      "left": "M1",
      "right": "M2",
      "tail": "M5",
      "loadLeft": "M3",
      "loadRight": "M4",
      "style": "back_to_back"
    }
  ],
  "orientations": {
    "M1": "gate_left",
    "M2": "gate_right",
    "RZ": "horizontal_l2r"
  },
  "tierOverrides": {
    "M3": 1,
    "RZ": 3,
    "M1": 4,
    "M5": 5
  },
  "columnOrderHints": [
    ["M3", "M1"],
    ["M5"],
    ["M4", "M2"]
  ],
  "netPolicies": {
    "VDD": "supply_local",
    "VSS": "supply_local",
    "vbias_n": "perimeter_bus",
    "vout1": "full_wire"
  },
  "criticalNets": ["VINP", "VINN", "vtail", "vout1", "VOUT"],
  "portSides": {
    "VINP": "near_pin",
    "VINN": "near_pin",
    "VOUT": "right",
    "VDD": "local_repeat",
    "VSS": "local_repeat"
  },
  "spacing": {
    "intra_group_gap_x": 8,
    "inter_group_gap_x": 14,
    "min_clearance_x": 5,
    "intra_stack_gap_y": 8,
    "inter_tier_gap_y": 9,
    "min_clearance_y": 6,
    "wire_track_pitch": 2
  }
}
```

### 枚举值说明

1. **`orientations`（器件语义朝向）**
   - `gate_left`（对应 Virtuoso `R0`）：MOS 栅极朝左，沟道在右（PMOS 源在上漏在下，NMOS 漏在上源在下）。
   - `gate_right`（对应 Virtuoso `MY`）：MOS 水平镜像，栅极朝右，沟道在左，上下源漏方向保持不变。
   - `vertical` / `vertical_flipped`（`R0` / `MX`）：二/三端无源器件或独立源垂直摆放（`P` 在上 `M` 在下，或翻转）。
   - `horizontal_l2r` / `horizontal_r2l`（`R90` / `R270`）：无源器件水平摆放（`P` 在左 `M` 在右，常用于级间米勒补偿电容/调零电阻）。
2. **`tierOverrides`（纵向电位层 `1..5`）**
   - `1`：顶层 PMOS（源接 `VDD`）或高端电流源；
   - `2`：PMOS 共源共栅叠管（Cascode）；
   - `3`：中间信号带（水平跨接 RC 补偿、耦合电容等）；
   - `4`：NMOS 差分对或 NMOS 共源共栅叠管；
   - `5`：底层尾流管、NMOS 电流镜负载或接地负载电容（源/负端接 `VSS`）。
3. **`netPolicies`（网络走线策略）**
   - `supply_local`：电源/地（或指定重复顶层端口）就近生成局部垂直/水平短桩抽头，不拉全局横跨线；
   - `bulk_local`：MOS 体端与源同网时生成就地短环（`localBulkShorts`），接顶层电源/偏置端口时生成短桩标签（`localBulkLabels`）；
   - `full_wire`：通过正交 Steiner 树就近连通全部端子；
   - `perimeter_bus`：保持物理单连通正交实线（满足 Virtuoso `schCheck` 内部网不断网要求），但引导水平主干沿底部外围母线走廊布设，避开核心信号区。
4. **`portSides`（顶层端口摆放方式）**
   - `near_pin`：紧贴目标器件栅极/引脚外侧生成水平端口旗标（最适合差分输入对 `VINP`/`VINN`）；
   - `left` / `right` / `top` / `bottom`：置于原理图外框对应侧；
   - `local_repeat`：对电源/地或多支路共用的顶层偏置端口，在各受控支路旁生成同名重复端口（`virtuoso-bridge-lite` 原生支持同名 `inputOutput` 端口自动合并到同一电气网络）。

## 三、`AuditReport`（`schem_gen.audit.v1`）签核门禁定义

`overallPassed = true` 要求以下三项同时为 `true`：
1. **`bridgeManifestValid`**：通过 `virtuoso-bridge-lite` 的 `load_schematic_manifest`、`load_process_map` 与 `plan_manifest_circuit` 校验，且 `afterViolationCount == 0`；
2. **`electricalPassed`**：实例集合、全部参数（`w/l/nf/m` 等）、含体端 `B` 在内的有序端子网络划分与输入网表 100% 一致，且所有内部网络在物理导线上构成单一连通分量（无 `SPLIT_INTERNAL_NET`）；
3. **`readabilityPassed`**：以下 6 项硬性几何违例全部为 `0`：
   - `symbolOverlapCount == 0`（器件本体无重叠）
   - `labelOverlapCount == 0`（参数文字与相邻符号、相邻文字及任何导线无重叠）
   - `wireThroughBodyCount == 0`（无导线穿过无关或自身符号内部）
   - `wireOverForeignPinCount == 0`（无导线擦过异网引脚）
   - `collinearForeignWireOverlapCount == 0`（无异网平行线段共线重叠）
   - `ambiguousCrossingCount == 0`（无拐角或 T 型接点落在异网导线上）
